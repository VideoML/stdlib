# Echo smear

`registerEchoSmear` from `@videoml/stdlib/effects/echo-smear` registers `videoml/echo-smear` version `1`. The registry fixture is a colored rectangle driven by absolute-time keyframes; each keyframe has `time`, `x`, and `y` and optional `rotation` (radians), `scale`, `opacity`, `hold`, and a pair of cubic position controls `control1`/`control2`. `fixtures/echo-smear/curved-spin-pause.json` includes a curve, a spin, and a pause. Motion parameters are finalized before mount, copied, and sampled at eight subframes per frame by default. Replacing a trusted custom motion through `updateMotion` invalidates and rebakes the trajectory before the next seek.

`createEchoSmear` also accepts a trusted pure motion sampler and target draw function for other static visual targets. Sampler rotations must be continuous unwrapped radians (including multiple full turns); wrapped angles discard turn history. The caller supplies a revision representing all sampler parameters and must call `updateMotion` after any change; do not use ambient time or mutable hidden sampler state. The target's content is drawn by that function at each recorded pose. Unlike the upstream DOM adapter this implementation does not copy arbitrary DOM styles, live media, filters, clipping, or 3D matrices. A consumer requiring those needs a separately reviewed adapter.

Copies show past position, rotation, scale and opacity, spaced over the configured percentage of a frame. The count follows half-frame motion, with a threshold and an edge-distance bound for rotation; `measurePoint` controls which fractional point activates the threshold. `maximum` uses isolated canvas lighten compositing, and `normal` uses source-over. Defaults mirror the upstream length 100, threshold 40, count multiplier 1, maximum 60 copies, and edge spacing 1.5 pixels. Baked tracks are limited to 30 seconds, 120 fps, eight subframes and 28,801 samples; canvas dimensions are at most 4096 per side and 4,194,304 pixels. Invalid or oversized requests fail rather than truncating.

The algorithm is adapted from Hyperframes commit `28181602fe2d9ffa38474a6e8155a89909a7b8aa`, `registry/components/echo-smear/echo-smear.html`, under Apache 2.0. The license is retained at `catalog/licenses/Apache-2.0.txt`. Local macOS Chromium browser captures and exact cross-worker comparisons passed; the pinned Linux/preview/export and encoded-video release gate remains P28 work.

For local browser smoke, run `npm run test:echo-smear:browser` with `P10_DEPS_ROOT` pointing to a package containing esbuild and Playwright, `P10_OUTPUT` to a task-owned output directory, and `VIDEOML_CHROMIUM_EXECUTABLE_PATH` to an existing browser. The fixture uses only local vector content. The local browser smoke passed; it does not mark the catalog fixture verified.

## Existing DOM targets

`attachDomEchoSmear(targets, driver, options, revision)` records already-mounted HTML elements or root SVG elements; do not attach to a child inside an SVG. The caller must finalize animation parameters before attaching and must not concurrently mutate the targets during the bake. The explicit driver provides `duration`, `fps`, `capture()` returning `{time,state}`, optional `discontinuities` listing exact jump times, an abort-aware `seek(seconds, signal)` that settles all target rendering, and a synchronous `restore(state)` that restores all caller-owned target state. The driver must honor the abort signal, including suppressing any late target mutation after abort. Seek callbacks are trusted code, not serializable effect parameters. `handle.ready` completes after recording and restoring the original state; `handle.seek(frame)` seeks the real targets and renders their past poses. `handle.update(newDriver, revision)` aborts pending work and rebakes, even when a revision is reused. `cancel()` or `dispose()` aborts, removes ghosts and restores the captured state; the caller owns the targets and their parent.

Each ghost preserves its snapshot's computed 2D transform including individual translate/rotate/scale, skew and transform origin; matrix3d uses nearest recorded sample. Opacity is interpolated, while filter, clip-path, visibility and other discrete visual state use the nearest sample. Content and resolved descendant styles are frozen at the original settled snapshot. Local SVG IDs are prefixed per ghost and internal URL/href references are rewritten so gradients, clipping and use references remain local. Canvas and video are frozen to PNG pixels; unavailable or tainted frames fail explicitly, and ghosts never play media. Audio, iframe, scripts, and embedded style elements are inert in ghosts. Pseudo-elements, cross-target SVG references, closed shadow roots, and arbitrary DOM mutations during recording are not captured. Canvas/video snapshots are limited to 4,194,304 pixels; total targets are limited to 8, sampled target poses to 65,536, frozen clone nodes to 4,096, and sampled style strings to 16 MiB. Oversized requests fail rather than truncate. `maximum` uses isolated CSS `mix-blend-mode: lighten`; `normal` uses ordinary stacking. CSS compositing support and screenshot capture are required. Local browser smoke passed for text, SVG, canvas and video targets, cancellation, visibility, perspective and seek order. Partial-opacity Maximum compositing matched the pinned upstream snippet at three sampled frames. Logs are `/tmp/p10-dom-fenced.log` and `/tmp/p10-upstream-fenced.log`, with captures under `/private/tmp/videoml-execution/artifacts/p10-dom-fenced/` and `/private/tmp/videoml-execution/artifacts/p10-upstream-fenced/`. These host-local artifacts are evidence, not portable package paths. Pinned Linux and preview/export verification remain P28 gates.
