# Seeded particles

Register `registerParticleEffects` from `@videoml/stdlib/effects/particles` with a VideoML effect registry. The IDs `videoml/particle-text-dissolve` and `videoml/particle-image-reveal`, version `1`, require caller-preloaded `blob:` or `data:` URLs in `context.assets.font` and `context.assets.image`, respectively; `fontAsset` and `imageAsset` select alternative asset keys. Missing assets fail at mount. The host must preload licensed bundled assets; remote, file, javascript and relative URLs are rejected. Blob URLs remain owned by the caller and are never revoked by the effect. This URL policy is not an asset sanitizer; bundle extraction and source validation belong to P17. Example fixture paths and their license are in `fixtures/particles/`. Text parameters include `text`, `density` (`low`, `med`, `high`), `direction` (`in`, `out`), and `accent` (`green`, `blue`, `violet`); image accepts the same density and accent values, with direction `ltr` or `center`. Default text is `Dissolve`; the reveal lasts 2.8 seconds and then holds. `exit` accepts `none`, `fade`, or `up` (default `none`), and `durationSec` defaults to 4; short durations compress the reveal and exit proportionally. Particle tables derive from the supplied context seed. Every seek paints directly from absolute frame/fps; text targets come from a once-rasterized font glyph, while image particles span the stage and accompany a matching image wipe or iris.

These implementations adapt the particle field and timeline concepts in Hyperframes commit `28181602fe2d9ffa38474a6e8155a89909a7b8aa`, registry/components/particle-text-dissolve and particle-image-reveal, under Apache 2.0. The license is in `catalog/licenses/Apache-2.0.txt`; no upstream media is used. Local macOS Chromium captures are smoke evidence; the pinned Linux/font release gate remains required.

`tests/particles-conformance-entry.ts` is a local P03 harness entry for each ID. Bundle it with `EFFECT` set to the selected ID and `.woff2`/`.svg` data URL loaders; its font and image are bundled, so no network is required. The local browser suite passed exact decoded-RGBA comparisons for repeated, reverse, random and partitioned seeks, with no external HTTP requests. Its captures and logs for the 2026-10-30 run are under `/private/tmp/videoml-execution/artifacts/p09-final2/` and `/tmp/p09-browser-final2.log`. Run `npm run test:particles:browser` with `P09_DEPS_ROOT` pointing to a package containing esbuild and Playwright, `P09_OUTPUT` to an output directory, and `VIDEOML_CHROMIUM_EXECUTABLE_PATH` to an existing browser. These local captures do not promote either catalog entry to verified; pinned Linux, preview/export parity and encoded-video release evidence remain P28 gates.
