# Shared animation demo migration (unverified)

The seven established names are exported by `getSharedDemo` and are adapted to the VideoML frame lifecycle by `createDemoEffect`. The existing Babulus registry aliases these names to the same React components for one minor release. `FramerMotionDemo` is also shared because MixAndMatchDemo composes it. These are migration candidates, not verified catalog entries: browser captures, random-seek conformance, packed-consumer tests and Babulus behavior tests are required before acceptance.

The Babulus Lottie source included an external animation whose rights have not been established. This migration does not copy it; the bundled badge is the neutral `DEFAULT_BADGE` generated in the Babulus source, and an explicit local animation can be supplied as a parameter. Babulus source code is MIT licensed; upstream notices for framework libraries and assets must be preserved by distributors. ThreeOrbit is replayed from its initial state for each requested frame, and p5 noise/random generators use the configured seed. Asynchronous anime, p5 and Lottie initialization is awaited by the shared adapter. p5 redraw waiters reject on draw failure or cancellation, and the adapter cancels them before deferred effect disposal. These design claims remain subject to browser verification.

`registerSharedDemos(registry)` registers version 1 descriptors under `videoml/demo/<established-name>` with parameter schemas and factories backed by these same components. The browser conformance fixture source is `tests/demo-conformance-entry.ts`; compile it with each `DEMO` name against the packed package and use the accepted toolchain conformance runner. Do not mark catalog entries verified without passing captures and primary visual review.

For Lottie timing, `tests/demo-timing.test.mjs` checks unequal source/project rates and loop versus clamp, and `tests/lottie-browser.test.mjs` compares the real rendered frames. The browser regression requires the installed dependencies plus `P06_DEPS_ROOT` pointing to a package containing esbuild and Playwright and `VIDEOML_CHROMIUM_EXECUTABLE_PATH` pointing to the existing browser. It remains unrun under the current disk gate.
