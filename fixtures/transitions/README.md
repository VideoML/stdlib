# Transition fixtures

`shader-sweep.xml` is an original VideoML fixture demonstrating the transition binding. It uses named local scene sources; hosts must supply browser-painted or native capture providers. It contains no upstream media. Shader formulas are adapted from Hyperframes commit 28181602fe2d9ffa38474a6e8155a89909a7b8aa under Apache-2.0; see `catalog/NOTICE.md` and `catalog/licenses/Apache-2.0.txt`.
